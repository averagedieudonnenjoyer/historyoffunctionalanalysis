Jean Dieudonné's "History of Functional Analysis" typeset in LaTeX.

I'm trying to stay as close as possible to the original book's style. The changes are documented in the file CHANGES.md.

Current status: the main text is done, a diagram is missing in the introduction, and the bibliography is incomplete. Now typos need to be corrected (both Dieudonné's and the newly-introduced ones), the style of the book should be brought closer to the original one, and minor TODOs have been placed in the text.

Bibliography is usually done by hand. Not all references have been added.

LuaLaTeX is recommended. I haven't tested it with other compilers.
